Carpeta reservada para video.

Esta version del juego no incluye archivos de video (trailer, cinematicas, etc.).
Se deja la carpeta lista por si mas adelante se agrega, por ejemplo:
  - trailer.mp4   (video promocional del juego)
  - intro.mp4     (cinematica de introduccion)

Para usarlos, se podria agregar una etiqueta <video> en index.html apuntando a
"assets/video/nombre_del_archivo.mp4".
